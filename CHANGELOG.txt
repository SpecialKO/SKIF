2.0.0
=====
 + Library: Added support for the EA app, itch.io, Ubisoft Connect and
     version 2 of the Epic Games Launcher.
 + Library: Added a grid view of covers, with a size slider, platform logos
     and drag and drop of new covers. Also available in Horizon mode.
 + Added support for animated covers (APNG and WebP), and WebP covers in
     general.
 + Covers can now be downloaded from IGDB for all platforms.
 + SKIF no longer keeps asking for covers a source does not have; it checks
     again after a week, or when Refresh is used in the cover menu.
 + Dropping a new cover on a game can now be undone.
 + Steam: Added support for the Steam client beta.
 + Steam: Fixed some games missing their cover.
 + Library: Select multiple games to change their category or favorite state
     at once.
 + Library: Pinned games are now favorites.
 + Library: Added filter history; F3 is a synonym for Ctrl+F. Added
     "Clear Filter" to the right-click menu.
 + Game details now show the technology a game uses, based on its files.
    * Special K is disabled by default for games with anti-cheat, and a
        warning is shown next to the launch button.
 + Reworked launch options, the launch bar and the Properties window.
 + Added environment variables and a working directory to launch options,
     including for custom games. Improved support for elevated launches.
 + Added an INI Editor for Special K's config files, with presets.
 + Added a Local Install Manager to install, reinstall and remove local copies
     of Special K.
 + Reordered the tabs.
 + Settings: Added in-game keybindings and improved gamepad button rebinding.
 + Added a service toggle in the bottom left corner.
 + The Start Service hotkey now also whitelists the game in the foreground,
     and restarts the service if Special K was already loaded in it.
 + Added an option to ignore the blacklist.
 + Jump list: Recently launched games are moved to the top, and fixed Xbox
     games missing from it.
 + Added translations: German, Pirate English and en-x-cat.
 + SKIF and the library start considerably faster.
 + Sharper game icons and covers, and better support for high-DPI and
     multi-monitor setups.
 + SKIF remembers a maximized window. Double-click the title bar to
     maximize/restore it.
 + SKIF now uses the system proxy settings.
 + Fixed several crashes, and a crash while saving no longer risks losing
     your categories, favorites and renamed games.
 + Fixed HDR detection on multi-monitor setups.
 + Fixed garbled text in some cases.
 + Use SKIF_SteamAppIDtxt=0 to remove steam_appid.txt.
 + Disabled UnX as it is no longer compatible.
